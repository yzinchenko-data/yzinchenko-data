# Дневник калорий

Личный трекер калорий и КБЖУ в одном HTML-файле плюс скрипт анализа выгрузки.

## Приложение (`index.html`)

- **Дневник по дням**: записи по приёмам пищи, редактирование граммовки и переноса между приёмами, кнопка «Как вчера».
- **Добавление еды**:
  - поиск по встроенной базе (~70 продуктов, на 100 г), по своим продуктам и недавним записям, блок «Часто едите»;
  - ручной ввод с возможностью сохранить порцию в свои продукты;
  - Claude считает КБЖУ по текстовому описанию или по фото тарелки;
  - свои продукты и рецепты из нескольких ингредиентов с учётом веса готового блюда, ☆ у записи сохраняет её в избранное.
- **Итог дня**: калории, БЖУ, клетчатка, сахар, соль и счётчик воды.
- **Сводка за неделю или месяц**: средние КБЖУ, дни в цели ±10%, вода, серия дней подряд с записями.
- **Вес**: график за 30 дней со скользящим средним, сравнение фактического тренда с ожидаемым по калориям.
- **Цели**: калькулятор по формуле Миффлина — Сан-Жеора, расход энергии для прогноза.
- **Экспорт в CSV**: записи о еде и сводка по дням.

Опубликованная версия (Claude Artifact) хранит данные в облаке. При локальном открытии `index.html` данные сохраняются в `localStorage` браузера, функции Claude недоступны.

## Анализ (`analysis/`)

`analyze_diary.py` строит отчёт по выгрузке из раздела «Данные»: покрытие данных, средние КБЖУ и попадание в цель, паттерны по дням недели и приёмам пищи, главные источники калорий, энергобаланс и оценку фактического расхода энергии по наклону тренда веса.

```bash
pip install -r analysis/requirements.txt
python analysis/analyze_diary.py --days kalorii-dni.csv --entries kalorii-zapisi.csv --out report
```

Результат: `report/report.md` и графики `kcal.png`, `weight.png`, `weekday.png`. Для содержательных выводов нужно хотя бы 4–6 недель записей и регулярные взвешивания.
