# Дневник калорий

Личный трекер калорий и КБЖУ в одном HTML-файле.

- дневник по приёмам пищи (завтрак, обед, ужин, перекус) с навигацией по дням;
- встроенная база из ~70 продуктов и блюд (значения на 100 г) и недавно добавленные продукты;
- ручной ввод и подсчёт по описанию словами через Claude;
- цели по калориям и БЖУ с расчётом по формуле Миффлина — Сан-Жеора;
- график калорий за 7 дней.

Опубликованная версия (Claude Artifact) хранит данные в облаке. При локальном открытии `index.html` данные сохраняются в `localStorage` браузера.
