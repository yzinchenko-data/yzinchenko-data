# 🧪 SQL & Pandas Lab

Локальный интерактивный тренажёр: загружаете свои CSV/Excel — и сразу тренируетесь на них в SQL и pandas, с готовым кодом загрузки, автопроверкой задач и историей запросов.

## Быстрый старт

```bash
cd sql-pandas-lab
pip install -r requirements.txt
streamlit run app.py
```

Откроется браузер на `http://localhost:8501`. Нет своих данных — нажмите **«Загрузить демо-магазин»** (orders / customers / products).

## Что умеет

| Раздел | Возможности |
|---|---|
| 📥 **Данные** | Drag-and-drop нескольких CSV/TSV/XLSX/XLS или подключение файла по пути без копирования. Автоопределение кодировки (utf-8 / cp1251), разделителя (`,` `;` `\t` `|`) и колонок-дат (в т.ч. `dd.mm.yyyy`). Каждый лист Excel — отдельная таблица. Для каждой таблицы: просмотр, профиль колонок (типы, пропуски, уникальные), **готовый код загрузки с полным путём** для pandas, DuckDB и Jupyter, переименование и удаление. |
| 🧮 **SQL** | Редактор на DuckDB (диалект близок к PostgreSQL: CTE, оконные функции, `strftime`, `ILIKE`, `SUMMARIZE`). Все таблицы каталога доступны по имени, шаблоны запросов, время выполнения, выгрузка результата в CSV, быстрый график, история. |
| 🐼 **Pandas** | Ячейка как в Jupyter: каждая таблица — переменная, есть `pd`, `np`, `dfs` и `sql("...")`. Результат — последнее выражение или `result`; `print` и графики matplotlib выводятся. Исходные данные не портятся — код работает с копиями. |
| 🎯 **Задачи** | 14 задач на демо-магазине от `COUNT(*)` до когорт и накопительных итогов, плюс **автогенерация задач под любую вашу таблицу** (группировки, доли, пропуски, дубликаты, динамика по месяцам). Решайте на SQL или pandas — проверка сравнивает значения, а не имена колонок. Подсказки, эталонные решения на обоих языках, прогресс. |
| 📓 **Jupyter** | Модуль `lab` для любых ноутбуков и шаблон `practice.ipynb`. |

## Использование из Jupyter

```python
import sys
sys.path.insert(0, r"путь/к/sql-pandas-lab")
import lab

lab.tables()                              # таблицы, размеры и пути
orders = lab.load("orders")               # DataFrame по имени
lab.sql("SELECT COUNT(*) FROM orders")    # SQL по всем таблицам
lab.path("orders")                        # путь к файлу
lab.add(r"C:/Users/me/Downloads/sales.xlsx")  # подключить новый файл
```

## Где лежат данные

Всё хранится в `sql-pandas-lab/data/`: загруженные файлы, `catalog.json` (таблицы и параметры чтения), `history.json` и `progress.json`. Папка в `.gitignore`, личные данные в репозиторий не попадают.
